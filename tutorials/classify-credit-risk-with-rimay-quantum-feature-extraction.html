I-classify ang credit risk gamit ang Rimay Quantum Feature Extraction ng Kipu Quantum

tala

Ang Qiskit Functions ay isang experimental na feature na available lang sa mga user ng IBM Quantum® Premium Plan, Flex Plan, at On-Prem (sa pamamagitan ng IBM Quantum Platform API) Plan. Nasa preview release status ang mga ito at maaaring magbago.

Tantiya ng paggamit: 2 minuto sa isang Nighthawk r2 processor. (TANDAAN: Tantiya lang ito. Maaaring mag-iba ang runtime mo.)

Mga layunin sa pagkatuto​

  • Maghanda ng tabular data na may categorical at numerical na column para sa Rimay Qiskit Function.

  • Mag-fit ng quantum feature mapping sa training data at i-map ang test data sa parehong run.

  • Mag-train ng mga klasikal na model sa mga feature na binago ng quantum, mag-isa at kasama ng orihinal na mga feature.

  • Ihambing ang mga resulta sa purong klasikal na baseline.

Mga paunang kailangan​

Bago mo simulan ang tutorial na ito, dapat pamilyar ka sa mga sumusunod na paksa:

  • Panimula sa Qiskit Functions

  • Supervised classification gamit ang scikit-learn

Background​

Maraming problema sa machine learning sa industriya ang may maliliit o katamtamang laki ng tabular dataset, kung saan hindi na puwedeng dagdagan ang data at humihinto na sa pag-angat ang accuracy ng model. Tipikal na halimbawa ang credit risk scoring. Gumagamit ang isang nagpapautang ng ilang dosenang attribute para magpasya kung malamang bang babayaran ng aplikante ang kredito.

Ang Rimay, isang Qiskit Function mula sa Kipu Quantum, ay nagdaragdag ng quantum preprocessing step sa ganitong pipeline. Ipinapatupad nito ang digitized counterdiabatic quantum feature extraction algorithm [1]. Ang bawat input feature ay minamapa sa isang qubit. Ang mga halaga ng feature at ang mutual information sa pagitan ng mga feature ang nagtatakda ng mga local field at coupling ng isang spin-glass Hamiltonian. Pagkatapos, pinapaunlad ng counterdiabatic dynamics ang quantum system papunta sa mga low-energy state nito, at ang mga single- at two-body expectation value na nasusukat sa dulo ang nagiging bago at quantum-transformed na mga feature. Nakukuha ng mga feature na ito ang mga nonlinear na ugnayan sa pagitan ng mga input, at puwede mo silang ipasok sa kahit anong classical model.

Gumagamit ang tutorial na ito ng German credit dataset mula sa OpenML [2], na may 1000 aplikante at 20 attribute, para mag-train ng random forest classifier. Una, gagawa ka ng classical baseline, pagkatapos ay ipapadala ang data sa Rimay, at panghuli ay ite-train ang parehong uri ng model sa mga quantum-transformed na feature, nang mag-isa at kasama ng orihinal na mga feature.

Requirements​

Bago mo simulan ang tutorial na ito, siguraduhing naka-install ang mga sumusunod na package:

  • IBM Quantum Compute client (pip install qiskit-ibm-runtime)

  • Qiskit Functions (pip install qiskit-ibm-catalog)

  • scikit-learn (pip install scikit-learn)

  • pandas (pip install pandas)

  • Matplotlib (pip install matplotlib)

Kailangan mo rin ng access sa Rimay function mula sa Qiskit Functions Catalog.

from qiskit_ibm_catalog import QiskitFunctionsCatalog
from sklearn.datasets import fetch_openml
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (
    accuracy_score,
    f1_score,
    precision_score,
    recall_score,
    roc_auc_score,
)
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import OneHotEncoder

def train_random_forest(x, y, n_estimators, max_depth):
    """Train a random forest classifier with fixed hyperparameters."""
    model = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        min_samples_split=5,
        min_samples_leaf=1,
        max_features="sqrt",
        random_state=42,
        n_jobs=-1,
    )
    return model.fit(x, y)

def evaluate(model, x, y):
    """Return the classification metrics of a trained model on a test set."""
    y_pred = model.predict(x)
    y_proba = model.predict_proba(x)[:, 1]
    return {
        "Accuracy": accuracy_score(y, y_pred),
        "AUC": roc_auc_score(y, y_proba),
        "F1 score": f1_score(y, y_pred),
        "Precision": precision_score(y, y_pred),
        "Recall": recall_score(y, y_pred),
    }

Step 2: I-optimize ang problema para sa pag-execute sa quantum hardware​

Binubuo at tina-transpile ng Rimay ang mga circuit para sa processor na pipiliin mo, kaya walang circuit na kailangang i-optimize nang mano-mano. Tukuyin ang bilang ng shot kada circuit, sa loob ng mga sumusunod na limitasyon:

  • Kailangan ng bawat feature ng isang qubit, kaya dapat kasing dami man lang ng mga feature ng dataset ang qubit ng processor.

  • Nagpapatakbo ang Rimay ng isang circuit kada row, training at test row nang magkasama. Isang job ay puwedeng humiling ng hanggang 10 milyong execution lang, kaya dapat manatili sa budget na iyon ang bilang ng row na i-multiply sa shots.

Tingnan ang dalawang limitasyon bago mo i-submit ang job.

Kuwentahin ang function size​

Tumatakbo ang bawat job sa isang function size, S, M, o L, na pumipili ng compute resources na gagamitin nito. Para sa Rimay, nakadepende ang size sa bilang ng row na minamapa ng isang job, training at test row nang magkasama. Kung humiling ka ng size na masyadong maliit, magfa-fail ang job na may error na 4600. Para sa mga size at limitasyon nila, tingnan ang Function sizes sa Rimay guide.

Dinedefine ng sumusunod na cell ang size calculator. Tumatakbo ito sa makina mo, binabasa lang ang data na ipinasa mo rito, at walang sinusubmit.

from os import PathLike
from typing import Any, Literal, Sequence, Sized

Size = Literal["S", "M", "L"]

# Upper bounds (inclusive) in samples.
_SMALL = 2_999
_MEDIUM = 9_999

FIT_TRANSFORM, TRANSFORM, DELETE = "fit-transform", "transform", "delete"

# Which positions of input_file hold samples, per mode. The labels in
# y_train submit no circuits of their own, so they are not counted.
SAMPLE_POSITIONS = {FIT_TRANSFORM: (0, 2), TRANSFORM: (0,)}

def calculate_function_size(problem: Sequence[Sized], **kwargs: Any) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    metrics = _measure(problem, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def _measure(problem: Sequence[Sized], **kwargs: Any) -> dict:
    """The samples the job submits."""
    return {"samples": count_samples(problem, kwargs.get("mode"))}

def count_samples(problem: Sequence[Sized], mode: Any) -> int:
    """Rows across the data sets of ``problem`` that carry samples."""
    if mode == DELETE:
        return 0
    if mode not in SAMPLE_POSITIONS:
        raise ValueError(f"cannot size mode {mode!r}")
    if _is_name(problem) or (
        isinstance(problem, (list, tuple))
        and any(_is_name(data) for data in problem)
    ):
        raise TypeError(
            "pass the data, not the file name: read each input_file, e.g. with "
            "pandas.read_csv, and pass the data sets in input_file order"
        )
    if not isinstance(problem, (list, tuple)):
        raise TypeError(
            "pass a list of data sets in input_file order, e.g. [x_train, y_train], "
            f"not a single {type(problem).__name__}"
        )
    return sum(
        len(problem[i]) for i in SAMPLE_POSITIONS[mode] if i < len(problem)
    )

def _is_name(value: Any) -> bool:
    """A file name or path rather than data."""
    return isinstance(value, (str, bytes, PathLike))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return metrics["samples"] <= _SMALL

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return metrics["samples"] <= _MEDIUM

Ipasa ang mga data set sa parehong ayos ng mga file sa input_file, kasama ang mode ng run:

size = calculate_function_size(
    [x_train, y_train, x_test], mode="fit-transform"
)
print(size)

Step 3: I-execute gamit ang Qiskit primitives​

Patakbuhin ang Rimay sa fit-transform mode. Magfi-fit ito ng quantum feature mapping sa x_train.csv at y_train.csv, at imamapa nito ang training at test set gamit iyon. Mahalaga ang ayos ng mga file sa input_file. Ilista ang training features, ang training labels, at pagkatapos ang opsyonal na test features. Ipasa ang size na kinuwenta mo bilang function_size.

job = rimay.run(
    mode="fit-transform",
    input_file=[
        "x_train.csv",
        "y_train.csv",
        "x_test.csv",
    ],  # This order matters
    backend_name=backend.name,
    shots=shots,
    function_size=size,
)
print(job.job_id)

Mag-train sa mga quantum-transformed na feature​

Mag-train ng random forest sa mga quantum-transformed na feature lang.

    xq_train, y_train, n_estimators=900, max_depth=15

Mag-train sa pinagsamang classical at quantum na feature​

Pagsamahin ang orihinal at ang mga quantum-transformed na feature, at i-train ang parehong model sa kombinasyon.

xh_test = np.hstack([x_test.to_numpy(), xq_test])

    xh_train, y_train, n_estimators=900, max_depth=15
)
results["Hybrid"] = evaluate(hybrid, xh_test, y_test)

Sinusukat ng AUC kung gaano kahusay ranggo ng isang model ang good sa ibabaw ng bad na kredito, na hindi nakadepende sa decision threshold, kaya ito ang pinakamakabuluhang metric sa imbalanced na dataset na ito (70% good na kredito). Sa mga benchmark ng Kipu Quantum, ang mga quantum-transformed na feature nang mag-isa ay umabot sa AUC na kahawig ng classical baseline, at ang hybrid model, na pinagsasama ang dalawa, ang umabot sa pinakamataas na AUC at F1 score. Kaya nagdaragdag ang mga quantum-transformed na feature ng impormasyong hindi naibibigay ng mga classical na feature nang mag-isa.

Konklusyon​

Ano ang natapos mo​

Sa tutorial na ito, natapos mo ang mga sumusunod:

  1. Naghanda ng real-world na credit risk dataset na may categorical at numerical na attribute para sa quantum feature extraction.

  2. Gumawa ng classical random forest baseline.

  3. Ginamit ang Rimay para mag-fit ng quantum feature mapping sa quantum hardware at imapa ang training at test set sa isang run.

  4. Na-train ang parehong model sa mga quantum-transformed na feature at sa pinagsamang mga feature, at inihambing ang mga ito sa baseline.

Mga pangunahing aral​

  • Bumabagay ang Rimay sa umiiral na machine learning pipeline bilang isang karagdagang preprocessing step. Nananatili ang data preparation at ang classical model mo.

  • Ang bilang ng qubit ang naglilimita sa bilang ng input feature, at ang bilang ng row na i-multiply sa shots ang naglilimita sa laki ng isang job.

  • Gamitin bilang default ang mga quantum-transformed na feature na isinama sa orihinal na mga feature, dahil magagamit ng model ang pareho.

Mga susunod na hakbang​

Mga rekomendasyon
  • Basahin ang Rimay guide para malaman ang lahat ng input, magmapa ng bagong data gamit ang mode="transform", at makita ang iba pang benchmark.
  • Basahin kung paano inilapat ang quantum feature extraction sa satellite image classification [3].
