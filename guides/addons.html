Advanced techniques - Mga Qiskit addon

Ang mga Qiskit addon ay koleksyon ng mga research capabilities para sa pagtuklas ng mga algorithm sa utility scale. Ang mga modular na software component na ito ay nagtitiwala sa matibay na pundasyon ng Qiskit at maaaring isaksak sa isang workflow para mapalawak o magdisenyo ng mga bagong quantum algorithm. Itinatampok ng page na ito ang mga available na tools sa mga pangunahing functional na kategorya para matulungan kang pumili ng mga kaugnay na kakayahan habang binubuo ang iyong mga workflow.

I-map ang mga domain problem​

Ang mga kakayahang ito ay espesyalista sa pag-map ng mga domain problem sa mga quantum operator at circuit para sa pagpapatupad sa isang quantum computer.

Optimization mapper
I-model ang mga optimization problem at i-map ang mga ito sa mga representasyong naiintindihan ng quantum computer.
Browse documentation →
Fermionic mapper
I-model ang mga fermionic quantum system at i-map ang mga ito sa mga qubit operator at circuit.
Browse documentation →
AQC-Tensor
Bumuo ng mga high-fidelity na circuit na may mas mababang depth gamit ang approximate quantum compilation with tensor networks.
Browse documentation →
Multi-product formulas
Bawasan ang Trotter error ng Hamiltonian dynamics sa pamamagitan ng weighted na kumbinasyon ng ilang circuit execution.
Browse documentation →

I-optimize ang mga circuit para sa hardware execution​

Ang mga kakayahang ito ay kapaki-pakinabang para mabawasan ang circuit depth at karaniwang may kasamang mas mataas na sampling overhead.

Operator backpropagation
Bawasan ang circuit depth sa mga expectation value estimation sa pamamagitan ng pagbabalik-propagasyon ng mga observable sa buong circuit.
Browse documentation →
Circuit cutting
Bawasan ang depth ng mga na-transpile na circuit sa pamamagitan ng pag-decompose ng mga entangling gate sa pagitan ng mga hindi magkaratig na qubit.
Browse documentation →

Pamahalaan ang noise para sa expectation value estimation​

Gamitin ang mga sumusunod na addon para pamahalaan ang noise habang binubuo ang mga quantum workload na nag-eestimate ng mga expectation value ng mga observable.

Propagated noise absorption
I-mitigate ang mga expectation value sa pamamagitan ng pagsukat ng target observable na may naisama na impormasyon ng noise model.
Browse documentation →
Shaded lightcones
Bawasan ang probabilistic error cancellation (PEC) sampling overhead sa pamamagitan ng pag-alis ng mga noise model term na may mababang epekto sa observable estimation.
Browse documentation →

Pamahalaan ang noise para sa mga sampling result​

Ang mga technique na ito ay kapaki-pakinabang para pamahalaan ang noise sa mga sampling result.

Sample-based quantum diagonalization
Tantiyahin ang spectrum ng mga quantum Hamiltonian sa pamamagitan ng pagproseso ng mga maingay na sample at pag-diagonalize sa isang pinababang subspace.
Overview →
SQD for HPC
Isang HPC-ready na implementasyon ng SQD addon, nakasulat sa modernong C++17 standards at dinisenyo para paganahin ang mga HPC workflow at application.
Browse documentation →
Measurement-based postselection
I-filter ang hindi Markovian na noise sa mga circuit sa pamamagitan ng pagsasama ng mga measurement-based postselection transpiler pass.
Read the API reference →
Matrix-free Measurement Mitigation (M3)
I-mitigate ang mga measurement error sa pamamagitan ng pagproseso sa isang pinababang subspace na tinukoy ng mga maingay na bitstring.
Browse documentation →

Mga sumusuportang kakayahan​

Gamitin ang mga kakayahang ito para suportahan at buuin ang iyong mga workflow na gumagamit ng ibang mga addon.

Addon utilities
Bumuo ng mga workflow na gumagamit ng mga addon nang mas mabilis sa pamamagitan ng koleksyon ng mga function para sa paglikha ng mga Hamiltonian, pagbuo ng mga Trotter time-evolution circuit, at paggamit ng pinakabagong error mitigation capabilities.
Browse documentation →
Pauli propagation
Isang framework para tantiyahin ang operator evolution, na maaaring gamitin para i-simulate ang mga expectation value at ipatupad ang mga error mitigation technique, tulad ng propagated noise absorption (PNA) at shaded lightcones.
Browse documentation →
