Mga Madalas na Tanong (FAQ)

Para sa mga FAQ na partikular sa mga execution mode, tingnan ang gabay na Qiskit Runtime execution modes FAQ.

Paano ko isi-cite ang Qiskit sa aking pananaliksik?​

I-cite ang Qiskit gamit ang kasamang BibTeX file.

Paano ko isi-cite ang isang IBM Quantum computer sa aking pananaliksik?​

Para sa mga research paper, hinihikayat namin ang mga may-akda na kilalanin ang IBM Quantum® sa pamamagitan ng:

We acknowledge the use of IBM Quantum services for this work. The views expressed are those of the authors, and do not reflect the official policy or position of IBM or the IBM Quantum team.

Ang mga sanggunian sa papel ay dapat gumamit ng sumusunod na citation:

IBM Quantum. https://quantum.cloud.ibm.com/, YYYY

Ang mga quantum processing unit sa papel ay dapat i-reference gamit ang kanilang natatanging pangalan (halimbawa, ibmq_vigo) at maaaring idagdag ang bersyon (halimbawa, ibmq_vigo v1.0.2). Hinihikayat din naming i-reference ang processor. Halimbawa:

In this paper we used ibmq_vigo, which is one of the IBM Quantum Canary processors.

Halimbawa ng pag-cite ng IBM Quantum program:

IBM Quantum (2025). Estimator primitive (Version x.y.z) [computer software]. https://quantum.cloud.ibm.com/

Paano ko isi-cite ang IBM Quantum Composer sa aking pananaliksik?​

Halimbawa ng citation para sa IBM Quantum Composer:

IBM Quantum Composer. 2025. url: https://quantum.cloud.ibm.com/composer

Hindi ko nakikita ang isang bagay sa user interface, tulad ng mga gawain sa administrasyon.​

Subukang pumili ng ibang account mula sa account switcher sa header ng IBM Quantum Platform na interface.

Gumagamit lang ako ng Open Plan, pero naglagay pa rin ako ng credit card. Sisisingilin ba ako?​

Hindi ka sisisingilin maliban kung gumawa ka ng Pay-As-You-Go instance at ginamitin ito para magpadala ng mga workload sa QPUs. Tingnan ang Manage cost para sa mga tagubilin sa pagtatakda ng limitasyon sa gastos at para malaman ang iba pang paraan ng pamamahala ng gastos.

Ano ang pagkakaiba ng API key at API token?​

Wala itong pagkakaiba. Ang mga terminong API key at API token ay ginagamit nang palitan. Makikita mo ang parehong termino sa dokumentasyon dahil gumagamit ng iba't ibang termino ang iba't ibang interface.

Ano ang pagkakaiba ng API token at bearer token?​

Ang API token ay isang pangmatagalang kredensyal na ginagamit para mag-authenticate sa Qiskit Runtime service. Ang bearer token naman ay isang pansamantalang kredensyal na ginagamit para mag-authenticate sa REST API sa hindi pinagkakatiwalaang kapaligiran. Hindi maaaring gamitin ang bearer token para mag-authenticate sa Qiskit Runtime service.

Kailangan ko bang pumili ng rehiyon na tinitirhan ko?​

Hindi. Maaari kang gumamit ng alinmang rehiyon. Tinutukoy ng rehiyon kung saan pinapatakbo ang mga trabaho at kung saan pinapanatili ang data. Bukod dito, makikita at magagamit mo lang ang mga instance na nilikha sa instance na naka-log in ka. Tandaan na ang us-east na rehiyon lang ang sumusuporta sa Open Plan.

Maaari ba akong kumonekta sa pamamagitan ng proxy server?​

Oo, pero kailangan mong gumamit ng Qiskit Runtime v0.44.0 o mas bago.

Ano ang patakaran sa pagpapanatili ng data?​

Pinapanatili ng IBM ang iyong (hindi pa tinanggal na) data ng trabaho at paggamit sa loob ng tatlong taon habang patuloy mong ginagamit ang Qiskit Runtime service.

Ano ang nangyari sa mga Python distribution tulad ng Qiskit Aer, Qiskit Nature, at Qiskit Experiments?​

Mula nang ilabas ang Qiskit SDK v1.0, ang command na pip install qiskit ay mag-i-install lamang ng Qiskit SDK. Ibig sabihin, ang ilang module na ginamit mo noon, tulad ng qiskit-aer o qiskit-nature, ay kailangan nang i-install nang hiwalay.

Bago ilabas ang Qiskit SDK v1.0, ang Qiskit ay binubuo ng maraming iba't ibang Python distribution, tulad ng qiskit-terra, ang compiler core; qiskit-aer, ang high-performance simulator; ang orihinal na IBM Quantum® provider; at ilang ngayon ay lipas na (obsolete) na package na nagbibigay ng mga partikular na eksperimental na algorithmic o experiment-running na feature.

Ang mga hiwalay na software package na ito ay pinagsama sa tinatawag na Qiskit metapackage, na nagpahintulot sa mga user na i-install ang lahat ng component na ito nang sabay-sabay sa pamamagitan ng pip install qiskit. Ang metapackage architecture na ito ay tinanggal nang ilabas ang Qiskit SDK v1.0, at ngayon ay kailangang i-install nang hiwalay ang bawat isa sa mga indibidwal na software distribution.

Kung gusto mong i-install ang mga package na dati ay kasama sa Qiskit metapackage, bisitahin ang Qiskit ecosystem para makahanap ng iba't ibang package na angkop sa iyong pangangailangan. Maaari mo ring basahin ang v1.0 migration guide para sa karagdagang impormasyon tungkol sa pagbabagong ito.

Paano ko isasara ang aking IBM Cloud account?​

Hanapin ang mga tagubilin sa pahina ng Closing an account.

Bakit nakakakita ako ng mensahe na hindi aktibo ang aking account kapag sinusubukan kong mag-log on?​

Kung nakita mo ang mensaheng "This account is inactive", bisitahin ang IBM Cloud documentation para malaman kung bakit at kung paano ito ayusin, o i-access ang IBM Cloud para i-verify kung mayroon kang mga nakabinbing aksyon na kailangang kumpletuhin sa iyong account.

Ano ang epekto ng device drift?​

Ang epekto ng device drift (pagkasira ng performance ng hardware sa paglipas ng panahon) ay nakasalalay sa maraming salik, tulad ng kailan huling pinatakbo ang mga calibration, ang partikular na eksperimentong isinasagawa, anumang TLS na aktibidad, at iba pa. Kung ang isang partikular na workload ay lubhang sensitibo sa mga error value ng mga parameter ng device, maaari kang magsagawa ng real-time na device parameter benchmarking sa pamamagitan ng pagsunod sa tutorial na ito sa IBM Quantum Learning.
